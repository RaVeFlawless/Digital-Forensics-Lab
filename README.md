# Digital Forensics Lab

## Descripción

Este repositorio contiene un proyecto académico relacionado con **informática forense digital**, desarrollado con el objetivo de practicar el análisis de evidencia digital y conocer algunas de las herramientas utilizadas durante una investigación forense.

Durante el proyecto se realizaron diferentes procedimientos para localizar, revisar y documentar información almacenada dentro de una evidencia digital.

## Objetivo

El objetivo principal fue aplicar una metodología básica de análisis forense para identificar información relevante dentro de una fuente de evidencia digital, manteniendo un proceso organizado y documentado.

## Herramientas utilizadas

- FTK Imager
- Autopsy
- ExifTool
- Windows
- Kali Linux
- Herramientas de análisis de metadatos

## Actividades realizadas

Durante el proyecto se realizaron actividades como:

- Identificación de archivos relevantes.
- Exploración de sistemas de archivos.
- Análisis de metadatos.
- Recuperación y revisión de información.
- Documentación de evidencia encontrada.
- Elaboración de conclusiones a partir de los resultados.

## Habilidades desarrolladas

Este proyecto me permitió desarrollar conocimientos relacionados con:

- Análisis forense digital.
- Manejo de evidencia.
- Investigación de archivos.
- Análisis de metadatos.
- Uso de herramientas forenses.
- Documentación técnica.

## Nota

Este repositorio tiene fines educativos. No contiene información confidencial, credenciales reales ni evidencia perteneciente a terceros.
